ConstructQuasilinearDiffusionTerm (Builder)
============================================

The :cpp:func:`ConstructQuasilinearDiffusionTerm` function constructs a
:cpp:class:`QuasilinearDiffusionTerm` from the DREAM settings hierarchy.
It supports two modes of operation and is called during simulation setup
for each kinetic grid that has quasi-linear diffusion enabled.

.. code-block:: cpp

   namespace DREAM {
       QuasilinearDiffusionTerm *ConstructQuasilinearDiffusionTerm(
           Settings *s,
           const std::string& mod,
           FVM::Grid *grid
       );
   }

The ``mod`` parameter identifies the module name in the settings tree
(e.g. ``"eqsys/f_hot"`` or ``"eqsys/f_re"``).

Two modes of operation
----------------------
The builder reads the ``quasilinearmode`` setting to decide whether to
enable the term at all, and then ``quasilinear/use_precomputed_matrix``
to select between the two modes:

Mode A: Pre-computed matrix (HDF5)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
Loads the diffusion coefficients from a pre-computed HDF5 file (e.g.
generated by a Python script). This mode is fast because the coefficients
are computed offline.

.. list-table::
   :header-rows: 1
   :widths: 35 15 50

   * - Setting path
     - Type
     - Description
   * - ``quasilinearmode``
     - integer
     - ``QL_DIFFUSION_MODE_INCLUDE`` (1) to enable, ``_NEGLECT`` (0) to disable
   * - ``quasilinear/use_precomputed_matrix``
     - bool
     - ``true`` for pre-computed mode
   * - ``quasilinear/precomputed_file``
     - string
     - Path to the HDF5 file containing pre-computed diffusion matrices
   * - ``quasilinear/amplitude``
     - real
     - Initial/constant wave amplitude
   * - ``quasilinear/start_inject_time``
     - real
     - Time at which wave injection starts (:math:`-1` = immediate)
   * - ``quasilinear/inject_cycle_duration``
     - real
     - Period of injection cycle (:math:`0` = continuous)
   * - ``quasilinear/ramp_time``
     - real
     - Ramp-up duration at each ON cycle (:math:`0` = step function)

Mode B: On-the-fly computation
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
Calculates the diffusion coefficients during the simulation using the
wave spectrum, dispersion relation, resonance solver, and coupling
strength classes. This mode includes the full physics but is more
computationally expensive at startup.

Settings available in this mode:

.. list-table::
   :header-rows: 1
   :widths: 35 15 50

   * - Setting path
     - Type
     - Description
   * - ``quasilinearmode``
     - integer
     - ``QL_DIFFUSION_MODE_INCLUDE`` (1)
   * - ``quasilinear/use_precomputed_matrix``
     - bool
     - ``false`` for on-the-fly mode
   * - ``quasilinear/harmonic_modes``
     - integer list
     - Harmonic numbers to include, e.g. ``-2 -1 0 1 2``
   * - ``quasilinear/amplitude``
     - real
     - Base wave amplitude
   * - ``quasilinear/num_k``
     - integer
     - Number of wavenumber samples in the spectrum
   * - ``quasilinear/num_ktheta``
     - integer
     - Number of angle samples in the spectrum
   * - ``quasilinear/k_min``
     - real
     - Minimum wavenumber (:math:`{\rm m}^{-1}`)
   * - ``quasilinear/k_max``
     - real
     - Maximum wavenumber (:math:`{\rm m}^{-1}`)
   * - ``quasilinear/ktheta_min``
     - real
     - Minimum propagation angle (rad)
   * - ``quasilinear/ktheta_max``
     - real
     - Maximum propagation angle (rad)
   * - ``quasilinear/use_simple_dispersion``
     - bool
     - Use simplified whistler dispersion (true) or PDRF (false)
   * - ``quasilinear/start_inject_time``
     - real
     - Injection start time
   * - ``quasilinear/inject_cycle_duration``
     - real
     - Injection cycle duration
   * - ``quasilinear/ramp_time``
     - real
     - Ramp-up time

Plasma parameters (B0, density) are read automatically from the radial
grid and ion density settings.

Behaviour when disabled
-----------------------
If ``quasilinearmode`` is ``QL_DIFFUSION_MODE_NEGLECT`` (0), the builder
returns ``nullptr`` and no quasi-linear diffusion term is added to the
equation system.
